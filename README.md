# Tarea 3 - Big Data: Procesamiento de datos con Apache Spark

## Descripción del proyecto
Este proyecto analiza datos de vehículos involucrados en accidentes de tránsito en Colombia utilizando Python y Apache Spark (PySpark).

## Objetivo
Realizar limpieza, transformación y análisis exploratorio de los datos para identificar patrones relacionados con la gravedad de los accidentes, los tipos de vehículos y los departamentos donde ocurren.

## Herramientas utilizadas
- Python
- Apache Spark (PySpark)
- Google Colab
- Pandas
- Matplotlib

## Análisis realizados
- Revisión y limpieza de datos.
- Análisis de la gravedad de los accidentes.
- Identificación de los tipos de vehículos más frecuentes.
- Análisis de los departamentos con más registros.
- Generación de gráficos estadísticos.

## Ejecución
El código se desarrolla en Google Colab. Para ejecutarlo, se debe cargar el archivo CSV de datos y ajustar la ruta del archivo según su ubicación.

## Resultados
Los resultados incluyen tablas estadísticas y visualizaciones sobre los vehículos involucrados en accidentes de tránsito en Colombia.
